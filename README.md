# Project Apogee

## Overview
Design, build, and fly a model rocket with a custom Arduino-based 
flight computer. Compare simulated vs real flight data.

## Goals
- Design a stable rocket in OpenRocket
- Build and fly the physical rocket
- Log altitude and acceleration data with Arduino
- Compare real flight data against simulation

## Hardware
- Rocket: BT-60 body tube, D12-5 motor
- Flight computer: Arduino Nano, BMP388, MPU-6050, MicroSD logger
